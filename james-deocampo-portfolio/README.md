# James Deocampo — Portfolio

Personal portfolio website for James Deocampo, Digital Marketer, GoHighLevel Expert and Social Media Manager.

**Live site:** https://james-deocampo.vercel.app

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole website: layout, styles (purple, blue & white, Poppins font) and scripts |
| `.gitignore` | Keeps Vercel's local `.vercel` folder out of the repo |
| `README.md` | This file |

## View it locally

Double-click `index.html` to open it in your browser. No install or build step needed.

## Edit contact details

Open `index.html` in a text editor and search for these placeholders:

- `+63 900 000 0000` (phone)
- `james.deocampo@email.com` (email, appears twice)
- `facebook.com/jamesdeocampo` (Facebook)

## Deploy

This is a static site. On Vercel, import this GitHub repo as a new project and deploy with the default settings (no framework, no build command).
